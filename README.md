# ADOPS-Transport

Sitio informativo público de una herramienta personal de transferencia verificada a Google Drive.

- `index.html`: página principal y condiciones de uso.
- `privacy.html`: política de privacidad.
- `styles.css`: estilos locales, sin dependencias externas.

El sitio es estático y no incorpora formularios, scripts, analítica ni cargas de archivos. Este repositorio solo contiene documentación pública de la herramienta. Los archivos transportados, las credenciales, los registros y la configuración de cada instalación se conservan por separado.

Publicación prevista: GitHub Pages, rama `main`, carpeta raíz. La URL definitiva se obtiene de Settings → Pages después del despliegue.
